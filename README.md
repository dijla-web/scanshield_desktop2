# ScanShield Desktop

تطبيق فحص أمان مواقع يشتغل بالكامل من جهازك - بدون سيرفر، مجاني، مفتوح
المصدر. يفحص: منافذ مفتوحة، إعدادات SSL، رؤوس الأمان، التقنيات
المستخدمة، جدار الحماية، والملفات الحساسة المنسية.

**متاح حالياً للدول العربية فقط** - البرنامج يتحقق من دولة المستخدم أول
ما يفتح (عبر خدمة تحديد موقع IP مجانية)، ويرفض المتابعة لو الدولة مو
ضمن القائمة. القائمة والطريقة موجودة بملف `core/geo_check.py` وتقدر
تعدّلها متى تبي.

## خطوات رفعه على GitHub والحصول على ملف exe (بدون ما تكتب كود)

1. سوِّ حساب على https://github.com إذا ما عندك وحد.
2. اضغط "New repository" وسمّيه مثلاً `scanshield`.
3. ارفع كل هذا المجلد (كل الملفات والمجلدات اللي بداخله) لنفس الريبو -
   تقدر تسحب وتفلت الملفات مباشرة بصفحة GitHub ("Add file" → "Upload files").
4. بعد الرفع، روح لتبويب **Actions** بأعلى الصفحة.
5. راح تشوف عملية اسمها "Build Windows EXE" تشتغل تلقائياً - انتظر
   دقيقتين لين تخلص (دائرة خضراء ✓).
6. اضغط عليها، وبالأسفل راح تلقى ملف باسم **ScanShield-Windows** -
   حمّله، وبداخله ملف `ScanShield.exe`.

هذا الملف هو التطبيق الكامل - أي شخص يحمّله من عندك (أو من صفحة الريبو)
ويشغّله مباشرة بدون ما يحتاج ينصب أي شي ثاني.

## شلون تشتغل محلياً على جهازك أنت (اختياري، للتجربة قبل الرفع)

إذا عندك Python مثبت بجهازك:

```bash
pip install -r requirements.txt
python app.py
```

## وين تنحفظ بيانات كل مستخدم؟

بجهاز المستخدم نفسه بس - مجلد اسمه `ScanShieldData` بمجلد المستخدم
الرئيسي (مثل `C:\Users\اسمك\ScanShieldData\scan_log.jsonl`). هذا الملف
يوثق أي فحص سواه وتاريخه وموافقته - دليله الشخصي، ما يوصلك انت ولا أي
حد ثاني.

## تنويه
